# Detailed Video Scripts

Hand-written, shot-by-shot production scripts for manual video generation (e.g. via Agent Opus), expanded from single-line prompts in the `funny` category of `prompts/available_prompts.json`.

These are separate from `prompts/available_prompts.json` / `used_prompts.json`, which hold the short one-line prompts the automated pipeline (`pipeline/runner.py`) consumes directly for Veo generation. Scripts here are not touched by the pipeline and won't be auto-consumed.

## Scripts

- [belly-rub-betrayal.md](belly-rub-betrayal.md) — a cat springs the belly-rub trap
- [peer-reviewed-spite.md](peer-reviewed-spite.md) — a cat pushes a book off a table while maintaining eye contact
- [captain-of-the-chaos-machine.md](captain-of-the-chaos-machine.md) — a cat rides a Roomba in total serenity
- [fish-tank-alibi.md](fish-tank-alibi.md) — a cat gets caught tormenting the goldfish and fakes innocence

Each script is 30s / 9:16 vertical, broken into 5 shots with camera direction, audio cues, and text overlays. Replace `[CAT]` with one consistent description of your cat and keep it identical across every shot in a script.
